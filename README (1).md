# Adidas Sales Analysis – Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Power BI Sales Analytics Dashboard** built to analyze Adidas sales performance across **products, retailers, regions, and sales channels**.

The dashboard transforms sales data into interactive KPIs and visualizations that help identify revenue trends, profitability patterns, product performance, retailer contribution, and regional opportunities.

## 🎯 Business Objective

The objective of this project is to provide a consolidated view of Adidas sales performance and support data-driven business decisions.

The dashboard focuses on:

- Tracking overall sales and profitability
- Comparing product performance
- Evaluating retailer contribution
- Analyzing regional sales performance
- Comparing sales channels
- Identifying sales trends and patterns
- Supporting business decision-making through interactive reporting

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data preparation and transformation
- **DAX** – KPI and calculated-measure development
- **Microsoft Excel** – Source data / data preparation

## 📌 Dashboard Analysis

### Sales Performance

The dashboard provides an overall view of sales performance through key metrics and interactive visualizations.

The analysis covers:

- Total Sales
- Units Sold
- Operating Profit
- Operating Margin
- Sales trends
- Performance comparisons

### Product Analysis

Product-level analysis helps evaluate which Adidas products contribute most to sales and profitability.

The dashboard can be used to compare:

- Product-wise sales
- Units sold
- Profitability
- Product contribution to overall performance

### Retailer Analysis

Retailer-level analysis provides visibility into sales contribution across different retail partners.

This helps identify:

- High-performing retailers
- Retailer sales contribution
- Profitability differences
- Opportunities for retailer/channel optimization

### Regional Analysis

The dashboard provides a regional view of Adidas sales performance.

Regional analysis helps understand:

- Sales contribution by region
- Regional performance differences
- Strong and weak markets
- Opportunities for regional growth

### Sales Channel Analysis

The dashboard compares performance across different sales channels, helping understand how each channel contributes to overall sales and profitability.

## 📈 Key Metrics

The dashboard uses Power BI measures and visualizations to monitor important business metrics, including:

- **Total Sales**
- **Total Units Sold**
- **Operating Profit**
- **Operating Margin**
- **Average Sales**
- **Sales Trends**

## 🔄 Data Preparation

The project involves preparing sales data for analysis before building the dashboard.

The Power BI workflow includes:

1. Importing the sales dataset
2. Cleaning and transforming data using Power Query
3. Checking data types and data quality
4. Creating calculated measures using DAX
5. Building interactive visualizations
6. Adding slicers and filters for analysis
7. Designing the dashboard for business-focused reporting

## 📊 Interactive Features

The dashboard is designed for interactive exploration using:

- Slicers
- Filters
- KPI cards
- Charts
- Tables
- Drill-down / category-level analysis where applicable
- Cross-filtering between visuals

Users can interact with the dashboard to analyze performance from different business dimensions.
